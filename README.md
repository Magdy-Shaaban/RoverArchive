# Forgotten Equipment — Mars & the Moon

**NASA Space Apps Challenge 2026 · Interactive 3D WebGL Archive**

تجربة تفاعلية ثلاثية الأبعاد تستعرض المعدات والمركبات التي تركها الإنسان على سطح المريخ والقمر — من مظلّات الهبوط والدروع الحرارية إلى المركبات الجوّالة ومحطات الرصد — على كرة كوكبية قابلة للتدوير، مع ملف تفصيلي لكل موقع.

- **23 موقعاً موثّقاً**: 12 على المريخ و11 على القمر.
- **ملف لكل موقع**: القصة، الإحداثيات، الكتلة المتروكة، القطع الموثّقة، والتحليل الجيولوجي والبيئي.
- **ملف علمي للكوكب**: الأبعاد الفيزيائية، تركيب الغلاف الجوي، والعصور الجيولوجية.
- **مؤثرات صوتية مولَّدة لحظياً** عبر Web Audio API (بدون ملفات صوتية).

---

## التشغيل

يجب تشغيل الموقع عبر خادم محلي (HTTP)، لأن المتصفحات تمنع تحميل خامات WebGL من `file://`.
(عند فتح `index.html` مباشرة يعمل الموقع بخامات إجرائية بديلة بدقة أقل.)

**الخيار 1 — Python:**

```bash
python -m http.server 5500
```

ثم افتح: `http://localhost:5500`

**الخيار 2 — VS Code:** افتح المجلد، ثم انقر بالزر الأيمن على `index.html` ← **Open with Live Server**.

## هيكل المشروع

```
index.html          الهيكل الأساسي: صفحة الاختيار، واجهة المستكشف، والنوافذ المنبثقة
style.css           نظام التصميم والتجاوب مع الشاشات وإمكانية الوصول
app.js              محرك Three.js: الكرة، الكاميرا، العلامات، والنوافذ
data.js             بيانات المواقع والمواصفات العلمية للكوكبين
textures.js         تحميل خامات الكواكب (مع بديل إجرائي)
audio.js            المؤثرات الصوتية عبر Web Audio API
assets/
  images/           صور المواقع (حتى 1600px)
  images/thumbs/    صور مصغّرة (480px) للشريط السفلي وشبكة المهام
  textures/         خرائط ألوان وتضاريس المريخ والقمر
```

جميع الصور والخامات محفوظة محلياً داخل `assets/` — الموقع لا يعتمد على روابط صور خارجية.
المكتبات الخارجية الوحيدة (بإصدارات مثبّتة): Three.js r128، GSAP 3.12.5، Lucide 0.460.0، وخطوط Google.

## حقوق الصور

- **NASA / JPL-Caltech** (ومعها MSSS، Cornell، ASU، University of Arizona) — صور المهام الأمريكية وصور Apollo (ملكية عامة).
- **HiRISE / University of Leicester** — صورة Beagle 2.
- **CNSA**، **ISRO**، و**Wikimedia Commons** — صور Zhurong وChang'e 4 وChandrayaan-3 ومركبات Luna/Lunokhod.
- خرائط الكواكب: مجموعة threex.planets (مشتقة من بيانات NASA/USGS).

يظهر مصدر كل صورة أسفلها داخل ملف الموقع.
